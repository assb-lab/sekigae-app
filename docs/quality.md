## アクセシビリティ

- `tests/e2e/a11y.spec.ts`: 全 5 画面 × ライト / ダークで axe（WCAG 2 A / AA）の serious / critical 違反 0。
  SVG キャンバス内の小さな文字はズームで拡大できるため対象外。
- 文字色は背景に対してコントラスト比の高い方（白 / 濃紺）を自動選択（`readableText`）。
- 席配置はドラッグの代わりにクリック配置・キーボード（矢印 / Enter / L / Delete）で操作でき、結果を読み上げる。
- `prefers-reduced-motion` でアニメーションを無効化。

## ブラウザ

- CI は Chromium（デスクトップ + Pixel 7 エミュレーション）で E2E を実行。
- Firefox / WebKit は `pnpm e2e:all-browsers`（CI では失敗してもマージを止めないジョブ）で確認する。
- スマートフォンは閲覧のみ。
